网红人格AI对话微信小程序前端开发方案
一、项目概述
1.1 项目背景
开发者已完成私有化服务器Agent部署与后端服务开发，并通过专属数据集蒸馏训练出各类网红专属人格模型，可精准复刻网红的说话语气、思维认知、表达习惯。本项目基于现有AI能力与已完成的后端服务，开发一款微信小程序前端，面向普通用户提供轻量化、沉浸式网红AI一对一对话服务，用户登录后可自由选择网红人格，实时与服务端AI Agent进行文字交互。

1.2 核心能力
- 私有化服务端AI Agent推理，独立部署、数据可控
- 多网红人格切换，语气、认知高度还原训练效果
- 微信小程序轻量化体验，无需下载、即开即用
- 实时文字双向对话，响应流畅、上下文连续

1.3 项目目标
快速落地可用的AI网红对话小程序前端，实现用户登录、人格选择、实时聊天、会话记录全流程打通，配合已完成后端服务，保障用户体验流畅、界面美观、合规安全。

二、技术栈选型
2.1 框架与语言
- 框架：微信原生小程序 + TDesign 组件库（腾讯官方小程序组件库）
- 语言：WXML + WXSS + JavaScript

2.2 状态管理
- 小程序原生 globalData + 页面局部缓存、组件间通信

2.3 网络请求
- 微信官方 wx.request（HTTP请求）
- wx.connectSocket（WebSocket长连接，用于实时聊天）

2.4 本地存储
- wx.setStorageSync / wx.getStorageSync（会话临时缓存、用户偏好）

2.5 组件库
- TDesign 微信小程序组件库（tdesign-miniprogram）
  - 使用场景：导航栏、按钮、卡片、加载动画、气泡、弹窗、表单等
  - 优势：腾讯官方出品，与微信原生高度兼容，组件丰富、视觉统一

三、微信登录与用户鉴权（核心流程）

3.1 登录整体流程
- 小程序启动 → 检查本地 token → token有效 → 直接进入首页（静默登录）
- 小程序启动 → 检查本地 token → token不存在/过期 → 触发微信登录 → 获取登录态 → 进入首页

3.2 微信登录详细流程
- 前端调用 wx.login() 获取临时 code
- 前端将 code 通过 wx.request 发送至后端 POST /api/user/login
- 后端通过 code 向微信服务器换取 openid 与 session_key
- 后端生成自定义登录态 token（含用户ID、openid、过期时间），返回前端
- 前端将 token 存入 wx.setStorageSync('token')，后续所有请求携带 token 至请求头 Authorization: Bearer <token>

3.3 token 管理机制
- token 有效期由后端控制（推荐7天），前端负责存储与续期
- 每次小程序启动时，前端检查本地 token 是否存在
  - 存在 → 携带 token 调用 GET /api/user/check 验证有效性
  - 有效 → 直接进入首页
  - 无效/过期 → 清除本地 token，跳转登录页重新授权
  - 不存在 → 跳转登录页

3.4 登录页交互设计
- 进入登录页自动调起微信授权弹窗（wx.authorize），获取用户昵称、头像
- 用户同意授权 → 获取用户信息（头像、昵称）→ 调用登录接口完成注册/登录
- 用户拒绝授权 → 显示"需要微信授权才能使用"提示 + 引导重新授权按钮
- 登录成功后自动跳转至首页，无需手动操作
- 支持"暂不登录、随便看看"模式（仅浏览人格列表，进入聊天时强制登录）
- TDesign 组件：Button、Loading、Dialog、Toast

3.5 用户信息获取
- 通过 wx.getUserProfile（已调整）或头像昵称填写能力（微信最新规范）获取用户头像、昵称
- 用户信息在首次授权时获取，后续登录直接从后端查询，无需重复弹窗授权
- 用户可在我页面修改昵称（本地维护），不影响微信授权信息

四、页面结构设计（4个核心页面）

4.1 登录页

4.2 首页 / 人格列表页
- 展示所有已上架网红AI，卡片式布局，支持点击选择
- TDesign 组件：Card、Grid、Search、Badge、Swiper（推荐位轮播）

4.3 聊天页
- 对话气泡、输入框、发送按钮、AI加载状态、消息列表
- 支持下拉加载历史消息、滚动至最新消息
- TDesign 组件：Chat（如有）、Bubble（自定义气泡）、Input、Button、Loading、Popup（更多操作）、Toast（提示）

4.4 我的页面
- 历史会话列表、清空记录、关于我们、免责声明入口
- TDesign 组件：Cell、List、Avatar、Button、ActionSheet、Footer

五、关键交互细节
- 聊天界面支持下拉刷新历史记录
- 消息发送防抖，防止重复点击发送多条消息
- 网络异常、接口超时、服务器过载友好提示（Toast / Dialog）
- AI回复过程展示"正在思考中"加载动画
- WebSocket断线自动重连，连接状态实时提示
- 页面切换保持聊天上下文不丢失

六、后端接口对接说明

6.1 用户接口
- 登录：POST /api/user/login → 传入 code，返回 token、openid、用户信息
- 验证登录态：GET /api/user/check → 传入 token，返回用户信息或 401 未授权
- 更新用户信息：PUT /api/user/update → 更新昵称、头像

6.2 网红人格接口
- 人格列表：GET /api/character/list → 所有上架网红信息
- 人格详情：GET /api/character/info → 单个人设详细参数

6.4 聊天对话接口（WebSocket）
- 长连接：ws://服务器地址/ws/chat
- 发送参数：token（鉴权）、character_id、message、session_id
- 接收参数：code、reply、context
- 鉴权方式：建立连接时校验 token，未授权连接直接关闭

6.5 会话记录接口
- 获取列表：GET /api/session/list → 请求头携带 token
- 删除会话：DELETE /api/session/del → 请求头携带 token

七、开发规范
- 使用 TDesign 组件库统一UI风格，避免自定义组件样式冗余
- 遵守微信小程序分包规范，控制主包体积不超过2MB
- 所有网络请求封装统一请求层，统一处理 token 注入、鉴权失败拦截（401自动跳转登录页）、错误码、超时
- WebSocket 连接统一管理，单例复用，避免重复创建；连接时携带 token 鉴权
- token 统一存储于 wx.setStorageSync('token')，请求拦截器自动注入 Authorization 请求头
- 页面生命周期合理管理，进入时检查登录态，退出时及时释放资源、断开连接
- 图片资源使用CDN或云存储，不打包至小程序内

八、合规与风险规避

8.1 内容合规
- 前端展示内容需经过后端风控过滤，禁止展示低俗、暴力、敏感内容
- AI回复展示前等待后端过滤结果

8.2 人物权益规避
- 禁止使用真实网红肖像、真实姓名商用，可使用二次元替代头像、化名人设
- 首页添加免责声明：仅为AI趣味模拟，非本人，无官方授权，仅供娱乐

8.3 平台合规
- 严格遵守微信小程序审核规范，确保授权流程、用户协议完整
- 用户隐私协议、数据使用说明需在前端清晰展示
- 用户拒绝授权时，不得强制退出，需提供"暂不登录"等合规引导

九、开发周期与迭代计划

9.1 第一阶段：基础版本（2-3天）
- 项目搭建，TDesign 组件库接入
- 登录鉴权全流程（wx.login → code → token → 存储 → 自动登录）开发
- 人格列表页、基础聊天功能开发
- WebSocket 对接联调

9.2 第二阶段：功能完善（1-2天）
- 上下文记忆展示、历史会话列表、记录回看
- token 过期自动续期、登录态异常处理
- 异常处理、加载状态、用户体验优化
- 我的页面完善

9.3 第三阶段：合规优化 & 上线（1天）
- 免责声明、合规文案展示
- 真机调试、兼容性测试、性能优化
- 小程序提交审核

十、后续可拓展功能
- AI语音对话：文字转语音，模拟网红音色对话
- 人设专属场景对话：直播、日常、问答等专属场景模式
- 对话分享功能：分享AI聊天记录给好友
- 付费解锁高端人设、无限次对话、更长记忆上下文
